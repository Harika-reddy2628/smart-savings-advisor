# Smart Savings Advisor for Students

## Overview
Smart Savings Advisor is a student-focused budgeting and expense tracking application that helps students manage their allowance, track expenses, and develop better financial habits.

## Features
- Expense Tracking
- Budget Management
- Savings Goal Tracking
- Spending Insights
- User-Friendly Interface

## Live Demo
https://smart-savings-advisor-for-students-09a818bd.base44.app/

## Why This Project?
Many students struggle to manage their monthly allowance and expenses. This application helps users monitor spending, track savings goals, and make smarter financial decisions.
